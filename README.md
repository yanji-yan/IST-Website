# 🎓 IST Batch 2025–2029

**Our Students. Our Achievements. Our Events. Our Memories.**

A digital archive created exclusively for **IST Batch 2025–2029**, preserving our students, achievements, events, awards, and memories throughout our journey.

## 🛠️ Tech Stack

### Frontend

* **HTML5** — Website structure and content
* **CSS3** — Styling, responsive design, animations, and visual effects
* **JavaScript** — Interactivity, dynamic content, and website functionality

### Backend

* **JavaScript** — Backend logic and API functionality

### Database

* **PostgreSQL** — Student, event, award, achievement, and memory data

### Storage

* **Supabase Storage** — Image and media storage

### Development Tools

* **VS Code**
* **Git**
* **GitHub**
* **Kali Linux**

## 🎯 Purpose

The IST Batch 2025–2029 website serves as a digital archive for our batch.

It allows us to preserve:

* 👨‍🎓 Student Information
* 🏆 Awards
* 🌟 Achievements
* 📅 Events
* 📸 Memories
* 📰 Batch Updates
* 💙 Important moments throughout our journey

## 🗄️ Database

The database stores information related to:

* `students`
* `events`
* `awards`
* `achievements`
* `memories`
* `users`

Database changes are organized inside the `database/migrations/` directory.

## 🎨 Website Features

* Responsive design
* Student profiles
* Events and announcements
* Awards and achievements
* Memory gallery
* Interactive animations
* Search and filtering
* Admin management
* Mobile-friendly interface

## 🔐 Privacy & Access

Because the website contains student information and photos, access to private information should be properly controlled.

Only authorized users should be able to manage or modify protected content.
